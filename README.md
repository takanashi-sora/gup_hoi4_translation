# gup_hoi4_translation

This repository contains localization files for the Hearts of Iron IV "Girls und Panzer" mod found on [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2844411050).

- `english/` holds the English texts.
- `replace/` overrides certain game strings.
- `simp_chinese/` now provides Simplified Chinese translations (work in progress).

Each `.yml` file is encoded as UTF-8 with BOM and uses Windows line endings.
